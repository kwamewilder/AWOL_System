# AWOL Management System

This is a simple desktop application for managing AWOL (Absent Without Leave) personnel records.

## Setup

1.  **Prerequisites:** Make sure you have Python 3 installed on your system.
2.  **No Dependencies:** The application uses the built-in `tkinter` library, so there are no external dependencies to install.

## How to Run

1.  Open a terminal or command prompt.
2.  Navigate to the directory where the `main.py` file is located.
3.  Run the following command:

    ```bash
    python main.py
    ```

4.  The application window should now appear.
